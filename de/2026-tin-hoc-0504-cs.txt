Câu 3. Cho hàm sau đây được viết bằng ngôn ngữ lập trình Python và C++, trong đó A là một mảng gồm $n$ số nguyên dương:
```
# Python
def F(A, n):
    j = 0
    for i in range(n):
        if A[i] % 2 != 0:
            if A[j] % 2 == 0:
                t = A[i]
                A[i] = A[j]
                A[j] = t
            j = j + 1
    return A[0] + A[n - 1]

// C++
int F(int A[], int n) {
    int j = 0;
    for (int i = 0; i < n; i++) {
        if (A[i] % 2 != 0) {
            if (A[j] % 2 == 0) {
                int t = A[i];
                A[i] = A[j];
                A[j] = t;
            }
            j = j + 1;
        }
    }
    return A[0] + A[n - 1];
}
```
Sau khi chọn một trong hai ngôn ngữ lập trình Python hoặc C++ để tìm hiểu hàm trên, có các ý kiến sau:
a) Hàm F có hai tham số. (Đ)
b) Sau khi thực hiện hàm F, mảng A không tồn tại phần tử có giá trị chẵn nào có chỉ số lớn hơn chỉ số của phần tử có giá trị lẻ. (S)
c) Nếu nhận vào hai đối số, mảng A là (2, 7, 6, 1, 4, 3, 5) và n = 7, thì hàm F trả về giá trị 9. (Đ)
d) Với mảng A bất kì, giả sử mảng B được tạo ra bằng cách sao chép mảng A rồi hoán đổi vị trí của một số phần tử thì kết quả trả về của hai lần gọi hàm F(A, n) và F(B, n) là bằng nhau. (S)
Lời giải: Hàm đưa các số lẻ lên đầu mảng, các số chẵn dồn về cuối, nên số chẵn luôn đứng sau số lẻ. Với mảng ở ý c), sau khi thực hiện được (7, 1, 3, 5, 4, 6, 2), trả về 7 + 2 = 9. Kết quả phụ thuộc thứ tự phần tử nên hoán đổi có thể làm thay đổi giá trị trả về.

Câu 4. Một hợp tác xã ứng dụng công nghệ IoT (Internet vạn vật) để thu thập dữ liệu một cách tự động. Dữ liệu bao gồm: loại đất, độ ẩm đất, nhiệt độ không khí, cường độ ánh sáng, giống cây trồng và được thu thập từ 2 000 lô đất trồng cây trong 5 vụ mùa. Cuối mỗi vụ mùa, các kĩ sư nông nghiệp của hợp tác xã sẽ đưa ra kết luận về tình trạng cây trồng là khỏe mạnh hoặc bị sâu bệnh trên từng lô đất. Các kết luận được đưa ra dựa trên quan sát thực địa và được xem là thông tin đáng tin cậy. Dựa trên tập dữ liệu đã thu thập, hợp tác xã muốn sử dụng mô hình học máy để xây dựng một hệ thống dự đoán tình trạng cây trồng cho lô đất mới. Có các nhận định như sau:
a) Bài toán dự đoán tình trạng cây trồng thuộc loại bài toán học máy có giám sát. (Đ)
b) Tình trạng khỏe mạnh hoặc bị sâu bệnh là các nhãn cần dự đoán. (Đ)
c) Để dự đoán về tình trạng cây trồng cho một lô đất mới, hệ thống có thể đưa ra kết quả mà không cần dữ liệu về thời tiết hay loại đất của lô đất đó. (S)
d) Hệ thống có thể thay thế hoàn toàn kĩ sư nông nghiệp trong việc ra quyết định phun thuốc bảo vệ thực vật. (S)
Lời giải: Dữ liệu huấn luyện đã có nhãn (kết luận của kĩ sư) nên đây là học có giám sát. Mô hình cần dữ liệu đầu vào của lô đất mới để dự đoán, và chỉ hỗ trợ chứ không thay thế hoàn toàn con người.
